# Kenney camp subset

Source: https://kenney.nl/assets/nature-kit
Local source: official Nature Kit 2.1 archive already used by FireFront.
License: CC0 1.0 (see License.txt). Attribution is not required; credit retained voluntarily.

Four byte-identical source GLBs are retained. No new downloads or dependencies.
Runtime uses compiled geometry in src/rendering/data/campArtwork.json.
Reproduce with: node scripts/prepareCampArtwork.mjs

Derivative: named-material FireFront colors (olive/ochre canvas, earthy wood, warm stone),
native shape/part variation, centered bases. Source GLBs remain unchanged.
The stone ring contains no flame; no decorative fire or simulation heat is added.
